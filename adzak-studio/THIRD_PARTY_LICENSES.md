# Third-party components and licences

> These notes are a practical summary for engineering and release decisions, **not legal advice**.
> Review the upstream licence texts (and the exact builds you ship) before a commercial release.

## Runtime components (bundled in the Windows installer)

| Component | Used for | Licence (summary) | Notes for distribution |
|---|---|---|---|
| **PySide6 / Qt 6** | Desktop UI | LGPL-3.0 (also GPL/commercial options) | Dynamically linked DLLs are shipped in the onedir build, so users can replace them (LGPL requirement). Keep the Qt DLLs as separate files. |
| **FFmpeg** (ffmpeg.exe) | Video/audio decode, encode, filters | LGPL-2.1+ for LGPL builds; **GPL-2.0+** for builds with `--enable-gpl` | The default `fetch_ffmpeg.py` downloads the BtbN **GPL** build (includes libx264/libx265). Shipping it means the installer must comply with GPL (offer corresponding source for FFmpeg and the x264/x265 builds; include licence text). Use an LGPL build if you do not want GPL obligations (then H.264/H.265 may need `h264_mf`/`hevc_mf` Windows encoders). |
| **libx264** | H.264 encoder (inside the GPL FFmpeg build) | GPL-2.0+ | As above. |
| **libx265** | H.265 encoder (inside the GPL FFmpeg build) | GPL-2.0+ (commercial licence also offered by MulticoreWare) | As above. |
| **Pillow** | Image I/O and processing | MIT-CMU (HPND) | Permissive. |
| **NumPy** | Numerical operations | BSD-3-Clause | Permissive. |
| **OpenCV (opencv-python-headless)** | GrabCut background removal, inpainting | Apache-2.0 (OpenCV); MIT (Python bindings); its wheel bundles LGPL-2.1 FFmpeg libraries | Permissive; includes notices. |
| **keyring** | Secure storage of API keys in Windows Credential Manager | MIT | Optional at runtime. |
| **Python runtime** (bundled by PyInstaller) | Interpreter | PSF licence | Permissive. |
| **PyInstaller bootloader** | Packaging the executable | GPL-2.0+ **with a bootloader exception** | Executables produced by PyInstaller are not subject to the GPL because of this exception. |
| **Inno Setup** (build tool only) | Creates the installer | Inno Setup licence (free redistribution of created installers) | Only used at build time. |

## Media content

* The application contains **no stock footage, music or fonts**. Text rendering uses the Windows system font (Arial) when available and Pillow's default font otherwise.
* Templates and sample graphics are generated by the code in this repository.

## Online services

* AI features that call an external provider send your prompt (and any text you choose) to that provider. The provider's terms and charges apply. No API key is shipped.
* No telemetry is collected by ADZAK Creative Studio.
