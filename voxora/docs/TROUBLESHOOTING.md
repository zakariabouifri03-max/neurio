# Troubleshooting

- **Cannot sign in / API unavailable:** check `/api/health`, PostgreSQL, DATABASE_URL, schema migration and server logs. The app does not fall back to mock data. Run commands from `voxora/`, not the original racing-game root.
- **Account created but no email:** open Mailpit at localhost:8025 for Compose, or private `storage/dev-mail` for the sandbox helper. Neither sends email to the real Internet. Fix SMTP then choose resend verification. Production needs a real configured SMTP provider.
- **Verification/reset link invalid:** tokens expire after one hour and are single-use. Request a fresh link. When inspecting `.eml`, decode MIME quoted-printable wrapping/`=3D`; do not paste the encoded transport text literally.
- **403 Untrusted origin:** set APP_ORIGIN/EXTRA_ORIGINS to exact trusted origins, including scheme and port. Do not solve by disabling CSRF checks or allowing `*`. Restart the API after changes.
- **Socket disconnected but HTTP works:** allow WebSocket upgrade at the proxy; inspect cookie/Origin and session expiry. Reload after logout/reset/revocation. Vite proxies `/socket.io` with `ws:true`.
- **No channels after joining:** fetch workspace again; check private allowlists, role and ban status. Private channels default to admins only. The current UI does not edit allowlists; use the authorized PATCH channel route.
- **No microphone/camera:** use HTTPS or localhost, allow OS/app permissions, check hardware and competing applications. Joining defaults to both off. A room-token response alone is not evidence of a working call.
- **Works locally but not across networks:** loopback `LIVEKIT_URL`/advertised media IP cannot be used by another computer. Deploy public WSS, correct media IPs, UDP/TCP ports, and TURN/TLS. The Arena web preview does not expose an SFU's UDP ports. See DEPLOYMENT.md.
- **Screen share denied in Electron:** use “Choose screen / window” first, select a source, and grant display permission. The generic SDK share button cannot silently capture a desktop source. Native capture is not available in an ordinary browser; use its built-in picker instead.
- **Screen audio missing:** OS/capture method dependent. The current Windows request supports entire-screen loopback only; window sharing is video-only. Real OS testing remains required.
- **Attachment rejected:** supported extensions are PNG/JPEG/WebP/PDF/TXT/MP4/MP3/OGG, with basic signature validation. Check configured size/quota and conversation access. Renaming arbitrary bytes does not make a valid image.
- **Prisma generation cannot download its engine:** a restricted network can use the documented generation-only overrides with the JS driver adapter. Never claim `/bin/true` runs migrations. Use normal Prisma migration tooling on a connected environment; SQL fallback is only for a new empty local database.
- **Electron download certificate error:** install a trusted corporate/intercepting CA using your environment's documented trust setup (`NODE_EXTRA_CA_CERTS` if appropriate), or build on a properly trusted Windows runner. Do not disable certificate verification. The sandbox packaging attempt failed here; no EXE was produced.
- **Packaged app says configuration required:** rebuild with public HTTPS VITE_API_URL and WSS LIVEKIT_URL. Do not put a database or SFU secret in a VITE variable.
- **Windows black window / graphics problem:** retry the packaged EXE with `--disable-gpu`. Keep driver and Electron current; collect `%APPDATA%` Voxora desktop logs (no message bodies/tokens). This fallback has not been verified on Windows here.
- **Tests cannot bind:** stop competing test suites on ports 55432/11026; do not run integration tests concurrently. A test crash may leave a PostgreSQL process; stop that test-owned process before cleaning only `test-results/pg`, never your development or production database.
- **Production dependency audit is clean but full audit is not:** build toolchains count too. Read STATUS.md; eight moderate inherited packaging advisories remain. A clean runtime audit is not blanket production approval.
