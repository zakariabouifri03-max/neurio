# ⚽ Pro Career 27 — مسيرة لاعب

**لعبة مسيرة لاعب كرة قدم كاملة، بالمتصفح، 100% من الصفر.**

A complete football player-career game that runs in the browser. Every club, league,
player, transfer, trophy and match is generated procedurally from a single seed —
there is **no licensed content, no downloaded data pack and no external API** anywhere.
Just open it and play.

```bash
# من جذر الريبو / from the repo root
python3 -m http.server 8000
# →  http://localhost:8000/pro-career/
```

No build step, no CDN, no dependencies. It is also a PWA: installs on your phone
home screen and works fully offline after the first visit.

---

## 🎮 كيفاش كتلعب — How it plays

1. **صايب اللاعب** — الاسم، المنتخب، المركز (مهاجم، جناح، صانع ألعاب، وسط، ظهير، قلب دفاع، حارس).
   اختياري: **🎮 اختبار المهارات** (3 ألعاب صغيرة: التسديد، ردّة الفعل، الذكاء) — النتيجة كتحدد
   المستوى ديالك والإمكانيات.
2. **من الأكاديمية للقمة** — كتبدا ف 17 سنة مع فريق متوسط (وماشي نجم)، خاصك تربح بلاصتك
   فالتشكيلة، تخدم فالتدريب، وتقنع المدرب.
3. **كل أسبوع**: ماتش الدوري (بماتش تفاعلي — قرارات + عرض 2D للملعب)، تدريب، أخبار، إصابات،
   وضغط الإدارة.
4. **كؤوس ومسابقات قارية** 🌍، و**المنتخب الوطني** وكأس العالم كل 4 مواسم.
5. **الصيف**: حفل جوائز، سوق انتقالات وعروض، عقود ورعاة، استثمارات (طاهي، فيزيو، PR...)، ثم موسم جديد.

## ⚽ الماتش التفاعلي — the match engine

الماتش كيتحسب من **سكريبت ديال 90 دقيقة** (هجمات، تسديدات، بطاقات، تشكيلات، تغييرات وإصابات)،
وفيه **لحظات قرار** كتقف عليك اللعب: لازم تختار ف 5 ثواني (ولا الكيبورد 1-4):

| اللحظة | الخيارات |
|---|---|
| 🎯 فرصة تسديد | قوة · زاوية · رفعة فوق الحارس · تمريرة لزميل |
| 🅿️ الكرة عندك | تمريرة بين الخطوط · قصيرة · عرضية · جري بالكرة |
| 🛡️ الدفاع | انزلاق · حتو · ضغط · تغطية |
| 🧤 حراسة | شمال · يمين · وقوف · خروج |
| 🎯 پينالتي / كرة ثابتة | 4 اختيارات لكل واحد |

القرار المزيان كيرفع احتمال الهدف (حتى ×1.5)، والقرار الخايب كيضيع فرص محققة.
المحرك نفسه (بلا لاعب) كيعطي نفس أرقام المحاكاة السريعة — يعني الماتشات متوازنة إحصائياً.

## 🧱 التقنية — tech

- **ES modules** خالصين، بلا أي مكتبة (لا Three.js ولا framework).
- `worldgen.js` — 12 دوري، **192 نادي**، **~4500 لاعب**، 40 منتخب، أطقم وألوان وملاعب ومدربين.
- `match.js` — plan → قرارات → resolve (نفس المسار للمشاهدة الحية وللنتيجة الفورية).
- `career.js` — 30 أسبوع + فترة صيفية كاملة: نمو اللاعب، ثقة المدرب، عقود، انتقالات،
  جوائز (الحذاء الذهبي، MVP، الكرة الذهبية)، ألقاب، أهداف الإدارة، منتخب وكؤوس قارية.
- `engine.js` — محاكاة سريعة لكل ماتشات العالم (حوالي 2900 ماتش فالموسم) فـ < 50ms.
- كل الحفظ فالجهاز (3 خانات)، والتقدم كامل offline.

## 🗂️ هيكل الملفات

```
pro-career/
├── index.html          # الهيكل + manifest + SW
├── manifest.webmanifest / sw.js
├── icons/              # أيقونات PWA
├── src/
│   ├── data.js         # الدوريات، المنتخبات، الأسماء، التكتيكات، الضبط
│   ├── worldgen.js     # توليد العالم + التشكيلات + جدول المباريات
│   ├── engine.js       # محاكاة سريعة + اختيار التشكيلة
│   ├── match.js        # محرك الماتش التفاعلي (plan/resolve)
│   ├── career.js       # المسيرة: مواسم، انتقالات، نمو، جوائز، منتخب
│   ├── ui.js           # الشاشات + الملعب 2D + نوافذ القرار
│   ├── rng.js          # RNG محدد + مساعدات + تنسيق
│   └── style.css
└── test/
    ├── smoke.mjs       # مسيرة كاملة بلا واجهة (8 مواسم)
    ├── stats.mjs       # توازن محرك الماتش (أهداف/تسديدات/تقييمات)
    └── ui.mjs          # اختبار الواجهة فـ jsdom (يحتاج jsdom)
```

```bash
node pro-career/test/smoke.mjs 8    # مسيرة 8 مواسم بلا واجهة
node pro-career/test/stats.mjs 400  # إحصائيات محرك الماتش
node pro-career/test/ui.mjs         # الواجهة (يتطلب: npm i jsdom)
```
