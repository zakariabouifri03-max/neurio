# Neurio Blocks — عالم المكعبات

لعبة فوكسل أصلية للأندرويد والويب: استكشف عالماً مولّداً من المكعبات، احفر، جمع الموارد، اصنع الأدوات، وابنِ بحرّية. الواجهة بالدارجة/العربية، والعالم كيتحفظ فالجهاز وكيخدم أوفلاين.

**هادشي لعبة مستقلة مستوحاة من ألعاب البناء والبقاء بالمكعبات؛ ماشي Minecraft رسمية وما كتستعملش ملفاتها أو أصولها.** ما نقدرش نوعد بنسخة مطابقة وكاملة من Minecraft، ولكن هاد المشروع فيه نواة لعبة قابلة للعب ومجموعة موارد ووصفات وأنظمة قابلة للتوسيع.

## جرّب اللعبة

- **APK جاهز:** `NeurioBlocks.apk` — حمّلو على Android وثبّتو. إلا طلب Android، سمح بالتثبيت من هاد المصدر.
- **الويب/PWA:** شغّل المشروع على استضافة HTTPS أو GitHub Pages، حلّ الرابط فـ Chrome على Android، ومن القائمة اختار **Add to Home screen / تثبيت**. بعد أول تحميل كيبقى يشتغل بلا نت.
- **محلياً للتطوير:**

  ```bash
  npm install
  python3 -m http.server 8000 --bind 0.0.0.0
  # افتح http://localhost:8000
  ```

## شنو كاين دابا

- عالم voxel كيتولد حسب **Seed**، بتحميل تدريجي للـchunks، تضاريس، كهوف، ماء، غابة، سهول، صحراء، ثلج ومستنقعات.
- منظور الشخص الأول، حفر ووضع البلوكات، حركة/قفز/جري، جاذبية وتصادم، وتعاقب الليل والنهار.
- وضع **Survival** فيه الصحة والجوع، كائنات مسالمة ووحوش بالليل؛ ووضع **Creative** للمخزون والبناء الحر.
- دليل داخل اللعبة فيه **70 عنصر** بين البلوكات والموارد والأدوات والطعام، و**29 وصفة** للصناعة والصهر.
- حقيبة وHotbar من 9 خانات، إعدادات للرؤية والجودة والحساسية والإحداثيات والصوت، وحفظ تلقائي للعوالم محلياً.
- تحكم بالكيبورد والماوس، أو عصا لمس وأزرار للبناء والحفر والقفز على الهاتف.
- لعب LAN مباشر بين لاعبين عبر WebRTC: مشاركة Offer/Answer بالكود، وحركة اللاعب والتعديلات على البلوكات والدردشة كيتشاركو.

## اتصال LAN

1. اللاعب المضيف يدخل لعالمه، يفتح الإيقاف `Ⅱ` ثم **استضف لاعباً على LAN**.
2. ينسخ Offer ويرسلو للاعب الثاني بأي وسيلة مناسبة.
3. اللاعب الثاني يضغط **دخل للّعب عبر LAN**، يلصق Offer، ويولّد Answer ويرجعو للمضيف.
4. المضيف يلصق Answer. منين يتّاصل الطرفان، العالم كيتحمّل عند اللاعب الثاني.

الاتصال مباشر بلا حساب ولا سيرفر، وخاص الجهازين يكونو على **نفس شبكة Wi‑Fi**. ما كاينش فهاد النسخة سيرفرات عامة أو matchmaking عبر الإنترنت؛ الشبكات اللي كتمنع اتصال الأجهزة ببعضها ممكن تمنع LAN.

## البناء وإعادة إنشاء APK

اللعبة ما كتحتاجش dependency runtime؛ Three.js موجودة داخل `vendor/`. البناء:

```bash
npm install
npm run check
npm run build
npm run build:apk
```

`npm run build` كينتج ملف HTML واحد مستقل `neurio-blocks.html`. `npm run build:apk` كيدمج هاد اللعبة فغلاف Android WebView الصغير الموجود فـ `tools/android-webview-shell.apk`، كيدير محاذاة جدول الموارد، وكيوقّع APK بتواقيع Android v1/v2/v3 عبر `apk_sign_ts`؛ OpenSSL غير كينشئ شهادة debug المؤقتة. ما كاين لا Android Studio لا Gradle. الـAPK المرفق sideload/debug للتجربة، **ماشي إصدار Play Store**؛ مفتاح التوقيع كيتبدل فكل build، وبالتالي خاص حذف النسخة المثبتة قبل التثبيت فوقها.

## هيكلة المشروع

```text
index.html / src/style.css    واجهة عربية متجاوبة وHUD
src/main.js                   القوائم والتحكم والحفظ وLAN
src/game.js                   اللاعب والفيزياء والتفاعل والليل/النهار
src/world.js                  توليد التضاريس والـchunks والمِشات
src/blocks.js                 دليل البلوكات والموارد والوصفات
src/inventory.js              الحقيبة وHotbar
src/entities.js               الحيوانات والوحوش
src/network.js                اتصال WebRTC محلي
src/storage.js                إعدادات وحفظ العوالم
src/audio.js                  مؤثرات مولدة محلياً
vendor/three.module.js        محرك 3D مضمّن
NeurioBlocks.apk              APK أندرويد جاهز للتجربة
```
