# Neurio Studio

تطبيق Android بواجهة عربية لتحسين الصور والفيديوهات ومقارنتها وتنزيل النتيجة. الملفات كيتعالجو محلياً داخل الجهاز.

## تحميل APK

GitHub Actions كيبني APK ديال Android 10 وما فوق، وكينشرو فـ GitHub Releases باسم `NeurioStudio.apk`.

## المزايا

- رفع الصور أو الفيديوهات من الهاتف.
- مقارنة قبل/بعد وضبط الحدة، تقليل التشويش، وحيوية الألوان.
- تكبير الصور 2× بالاستيفاء المحلي، مع تصدير PNG.
- معاينة الفيديو بتأثيرات محلية وتصديره بصيغة MP4 أو WebM حسب دعم WebView.
- حفظ الصور والفيديوهات المحسّنة داخل `Downloads/Neurio Studio`.

## ملاحظة مهمة عن AI

حالياً لا يوجد نموذج AI خارجي أو API مربوط بالمشروع. تحسين الصورة يستخدم خوارزميات محلية للحدة والألوان وتقليل التشويش؛ وخيار 2× يستخدم الاستيفاء العادي وليس Super-resolution توليدياً. لإضافة AI حقيقي يلزم ربط التطبيق بخدمة خلفية ونموذج مناسب، بدون وضع مفاتيح API في التطبيق.

## بناء APK يدوياً

التطبيق يحتوي مشروع Android أصلي في `android/`. يحتاج Java 17 وAndroid SDK 35 وGradle 8.9:

```bash
cd android
gradle --no-daemon :app:assembleDebug
```

الـ APK الناتج:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```
