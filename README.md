# 🎥 STREAMER LIFE 2 (the new one!)

A full 3D first-person **streamer life simulator** in the spirit of *Streamer Life Simulator 2*:
you arrive broke in the foggy forest town of **Cedar Creek**, rent a tiny room above the noodle
shop, buy a mic, go live on your PC, upgrade your setup, buy furniture, cars and houses —
all the way to the **Neon Mansion and 1,000,000 followers**.

**▶ Play in browser:** serve the folder and open `/streamer/` (or open `streamer/streamer-life-2.html` directly):

```bash
cd streamer && python3 -m http.server 8000   # → http://localhost:8000
```

On Windows just double-click **`StreamerLife2-Windows.bat`** (opens the game in an Edge/Chrome app window).

## 📱 APK — `StreamerLife2.apk` (ready, signed)

A real signed Android APK (WebView shell, fullscreen, works offline) is in the repo root.
Install: download to phone → tap → allow unknown sources → play.
- package `com.cedarcreek.sl2` · minSdk 21 (Android 5+) · signed v1+v2+v3
- Rebuild anytime: `sh tools/build-apk.sh` (see below for the npm toolchain).

## 🖥️ EXE (Windows x64)

A full NW.js desktop build is generated by:

```bash
# one-time toolchain (everything comes from the npm registry, no Android Studio / Gradle / Visual Studio):
mkdir -p /tmp/gb && cd /tmp/gb && npm init -y && npm i esbuild javajre-linux-64 aaptjs3 @drxiaozhi/minapk
curl -sL -o /tmp/nw/win.tgz https://registry.npmjs.org/@nwjs-binaries/win-x64/-/win-x64-0.87.0-sdk.tgz
mkdir -p /tmp/nw/win && tar xzf /tmp/nw/win.tgz -C /tmp/nw/win --strip-components=1
# build game + exe:
node tools/build-streamer.mjs && sh tools/build-exe.sh
# → StreamerLife2-win64.zip (extract, double-click StreamerLife2.exe)
```

No-install alternative: `StreamerLife2-Windows.bat`.

## 🎮 The game

- 🏘️ **Cedar Creek**: foggy forest town — lake with guardrail, pines, main street with
  **Homestead Foods** (groceries + work shifts), **Tech Shack** (instant PC gear), **Cozy Timber**
  (furniture), **Cedar Realty** (houses), **Cedar Motors** (cars), pedestrians, traffic,
  street lamps, day/night cycle, lit windows at night.
- 💻 **Your PC runs a little OS** with the classic apps: **Computers** (CPU/GPU/RAM/monitor),
  **Zamazor** (mics, webcams, chairs, RGB, furniture — delivered next day), **OPS**
  (stream key, bitrate, quality 480p→4K, refresh, category, **GO LIVE**), **Web** (chirp posts),
  **Wallpapers**, **Virus Scanner** (0 viruses, $50 premium 👑), **Bank**.
- 🎥 **Streaming**: live viewer curve, scrolling chat, donations 💸, viral events 🚀,
  followers/ads/sponsors; 10 streamable games from *Block Craft* to *Star Odyssey X*
  (incl. a *Bash Baqi Racing* cameo 🏁).
- 🏠 **5 homes** to buy & decorate (22 decor slots in the mansion): Rented Room → Mobile Home →
  Town House → Cabin → Neon Mansion. Furniture placement with **B**.
- 🚗 **4 cars** with **first-person cockpit** (dashboard, steering wheel, mirrors) — Q to exit, E brake.
- 📈 **Story**: 9-quest chain by email, sponsors (Chipz Cola 🥤…), milestones, level/XP, energy & hunger,
  sleep/rent/deliveries, fan photo events, win screen at 1M followers.
- 👥 **MULTIPLAYER (2 players, LAN & online, no server)**: WebRTC co-op — host sends an invite code,
  friend pastes it and sends an answer code back. You see each other in town, chat (T), and
  **co-op streams pay x1.5** when your friend is nearby. Everything can be done together.
- ⚙️ **Settings**: volumes, sensitivity, FOV, graphics (shadows on/off). Progress autosaves.

### Controls

| Action | Keys |
|---|---|
| Move / look | `WASD` + mouse (pointer lock) · touch joystick + drag on phone |
| Interact | `E` (or tap button) |
| Run | `Shift` |
| Exit car / handbrake | `Q` / `E` |
| Decorate (at home) | `B` |
| Chat (multiplayer) | `T` |
| Pause | `Esc` |

## 🧱 Streamer Life 2 tech

- 100% procedural Three.js: canvas textures (asphalt, floral wallpaper, wood siding, lake…),
  merged pine forests, instanced street-lamp glow, ACES tone mapping, soft shadows, fog.
- All SFX + lo-fi radio synthesized with Web Audio (engine hum included).
- Single-file build (`streamer/streamer-life-2.html`) → APK asset & offline play; PWA + service worker.
- `node tools/smoke-node.mjs` runs a headless simulation test (walk/drive/houses/quests).

```
streamer/
├── index.html        # UI layers (menus, HUD, PC OS, stream overlay, touch)
├── src/
│   ├── main.js       # world conductor: time, sky, quests, economy, MP glue
│   ├── city.js       # Cedar Creek (roads, lake, shops, houses, pines, traffic)
│   ├── houses.js     # interiors, desk setup, furniture slots
│   ├── player.js     # FP controller + cockpit driving
│   ├── pc.js         # the PC OS: Computers/Zamazor/OPS/Web/Wallpapers/Virus/Bank + live stream
│   ├── mp.js         # WebRTC co-op (invite/answer codes)
│   ├── ui.js         # menus, shops, realty, dealer, decorate, chat, touch
│   ├── npc.js        # chibi humans + cars + cockpit
│   ├── data.js       # parts, furniture, houses, cars, games, quests, sponsors
│   ├── tex.js / audio.js / save.js / util.js
└── vendor/           # three.js r170 (git-ignored copy; real one at ../vendor)
```

## 🔧 APK/EXE toolchain (no Gradle, no Studio)

`tools/build-apk.sh` uses, all from npm: `javajre-linux-64` (JRE 17), `aaptjs3` (aapt2 linux),
`@drxiaozhi/minapk` (android.jar, ecj, d8, apksigner, keystore). Pipeline:
aapt2 compile/link → ecj → d8 → inject classes.dex → apksigner (v1+v2+v3 ✔).
