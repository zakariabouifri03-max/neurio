# Neurio Studio

واجهة ويب عربية لتحسين الصور والفيديوهات ومقارنتها وتنزيل النتيجة. التطبيق يشتغل محلياً في المتصفح، وهو قابل للتثبيت كـ PWA.

## التشغيل

لا يحتاج المشروع إلى build أو dependencies. شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المتوفر حالياً

- رفع الصور بالسحب والإفلات أو من الجهاز، مع معاينة مقارنة قبل/بعد.
- ضبط الحدة، تقليل التشويش، وحيوية الألوان، مع إعدادات جاهزة وتصدير PNG.
- تكبير محلي 2× بالاستيفاء داخل المتصفح.
- رفع الفيديو، معاينته مع فلاتر محلية مباشرة، ثم تسجيل النتيجة وتصديرها عبر `MediaRecorder` عندما يدعم المتصفح ذلك.
- معالجة ملفات الصور في Web Worker، بدون رفعها إلى خادم.

## ملاحظة مهمة عن AI

حالياً لا يوجد نموذج AI خارجي أو API مربوط بالمشروع. تحسين الصور يستخدم خوارزميات محلية للحدة والألوان وتقليل التشويش؛ وخيار 2× يستخدم الاستيفاء العادي وليس Super-resolution توليدياً. معالجة الفيديو محلية أيضاً. لإضافة رفع دقة AI حقيقي (مثل نموذج super-resolution أو إزالة ضجيج متقدمة)، يلزم ربط واجهة آمنة بخدمة خلفية ونموذج مناسب؛ لا تضع مفاتيح API في كود المتصفح.
