# 🏎️ Cartoon Drift — طوموبيلات كارتون

لعبة سباق طوموبيلات **ستايل كارتون** خدّامة فالمتصفح، بلا تنزيل وبلا مكتبات — ملف HTML واحد.

## 🎮 اللعب

- **6 طوموبيلات** مختلفة فالسرعة و الـ grip (Mini Pop, Beach Buggy, Muscle Red, Mint Turbo, Midnight, Grape Racer)
- **3 عوالم**: 🏙️ مدينة الكارتون · 🏜️ صحراء الدريفت · ❄️ جبل الثلج
- حلبة كتتولد أوتوماتيك (Catmull-Rom) فكل سباق، 3 دورات ضد 5 منافسين
- **دريفت** فالمنعرجات، **نيترو** (SPACE)، **فلوس** 🪙 فالطريق، سكيد ماركس و دخان
- شاشة نتائج، أفضل وقت محفوظ فـ localStorage

## 🕹️ التحكم

| الجهاز | التحكم |
| --- | --- |
| 💻 PC | `WASD` / الأسهم · `SPACE` نيترو · `R` إعادة |
| 📱 تيليفون | أزرار لمس (غاس أوتوماتيك) · `🔥` نيترو |

## ▶️ التشغيل محلياً

```bash
python3 -m http.server 8080
# حل http://localhost:8080
```

## 📄 الملفات

- `index.html` — اللعبة كاملة (HTML + CSS + JS + Canvas 2D)
- `sw.js` — kill switch كيمسح الكاش القديم ديال النسخة السابقة
