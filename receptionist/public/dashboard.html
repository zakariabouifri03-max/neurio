Go live checklist

Take this AI receptionist from demo to answering real calls.

  • ✅ AI brain ready —
  • ⬜ Get a US phone number — sign up at Twilio, buy a local number (~$1.15/mo).
  • ⬜ Point Twilio at this server — in your Twilio number's Voice settings set the webhook to POST https://YOUR-SERVER/voice/incoming
  • ⬜ Deploy this server — Render, Railway, or any VPS with Node 20+. Set PORT and (optional) OPENAI_API_KEY.
  • ⬜ Connect payments — create Stripe Payment Links and paste them into the pricing buttons on the landing page.
  • ⬜ Test with a real call — dial your Twilio number and book an appointment by voice. Check it lands in the Appointments tab.
