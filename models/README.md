# Original 3D models

These self-contained **glTF 2.0 binary (`.glb`)** files are generated by the browser games' own export controls. No model or texture is extracted from The Forest, Watch Dogs, or another commercial game.

## HOLLOWPINE

### `hollowpine-forest-campsite.glb`

An original forest-camp diorama: conifer trees, ferns, rocks, fallen timber, a branch-built lean-to, and a campfire, arranged on a circular ground slice. It is a small environment asset, **not the entire playable map**. Static flame geometry is included; wind, lighting changes, particles, and survival logic are not.

### `hollowpine-survivor.glb`

Original hiker with a beanie, layered clothing, boots, utility backpack, and field hatchet. Approximately human scale, facing −Z, with named parent groups for the spine, head, shoulders / elbows, and hips / knees. The export is a **static pose with articulated parts**, not a skinned skeleton or a production-ready rig. It contains **no animation clips**; walking, chopping, and jumping in the game are procedural node-transform animations.

### `hollowpine-field-hatchet.glb`

Standalone original prop with a steel head, hardwood handle, and leather grip. Static PBR geometry, approximately half a meter long, with no external dependencies.

All three are generated in `src/hollowpine/models.js`. Preview or regenerate them at **HOLLOWPINE → 3D Models → Download .GLB**. The viewer can rotate with drag / arrow keys and zoom with the wheel / plus / minus.

## GHOSTLINE archive

### `echo-operative-carbon.glb`

Original procedural ECHO character with the carbon jacket palette, backpack, cap / hood, face covering, boots, radio, and profiler phone. Approximately two meters tall, facing −Z. Like the survivor, this is a static articulated hierarchy, **not a skinned rig and with no embedded animation clips**. Other palettes are available at **GHOSTLINE → Operative → Download 3D Model**.

Source: `src/ghostline/operative.js`.

## Import and validation

- **Format:** glTF 2.0 binary; embedded geometry, PBR materials, and any textures.
- **Coordinates:** meters, Y-up. Transform groups are retained where articulation is relevant.
- **Blender:** File → Import → glTF 2.0 (.glb/.gltf).
- **Game engines:** use an appropriate glTF importer. Add your own colliders, LODs, engine-specific shaders, skinned rig / animations, and gameplay components as required.
- **Validation:** `npm test` runs the Khronos glTF Validator against all four included files and checks for external image / buffer dependencies. Unused texture-coordinate informational messages are harmless; errors and warnings are asserted to be zero.
- **Regeneration:** with the dev server running, `npm run test:browser` refreshes the three HOLLOWPINE exports; `npm run test:browser:ghostline` refreshes ECHO.

These assets use original procedural geometry and do not reproduce or redistribute another game's models.
