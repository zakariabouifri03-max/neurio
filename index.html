واتساب على الكمبيوتر

كيفاش توصل الصورة المحسّنة؟

المتصفح ما يقدرش يبدّل كاميرا واتساب بوحدو. استعمل OBS Virtual Camera كجسر مجاني بين نور ستوديو وواتساب.

  1. 1شغّل الكاميرا هناسمح للمتصفح يستعمل الكاميرا، وضبط الضوّ والوضع اللي مناسب للنت.
  2. 2فتح عرض الكاميرا فقطكليكي «عرض الكاميرا فقط» باش تبقى غير الصورة باينة. زر Esc كيرجعك للاستوديو.
  3. 3فـ OBS زِد Window Captureاختار نافذة المتصفح اللي فيها نور ستوديو، ومن بعد كليكي Start Virtual Camera.
  4. 4اختارها فواتسابWhatsApp Desktop → Settings → Video → Camera → OBS Virtual Camera.

مهم: نور ستوديو كيحسّن الضوّ وكيخفّف دقّة المصدر، ولكن ما كيزيدش سرعة الإنترنت. واتساب هو اللي كيتحكّم فالجودة النهائية حسب الشبكة. هاد الربط خاصّو كمبيوتر وOBS؛ الهاتف ما كيدعمش هاد الطريقة.
