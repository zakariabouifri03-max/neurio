# Neurio Restore Android app

Shows images and videos available through Android MediaStore, including trashed entries exposed to the app. Android requests user confirmation before restoring a trashed entry. Accessible files can be copied to Downloads/NeurioRestore. Nothing is uploaded. Requires Android 11 or newer. Give full media permission for a complete scan; Android's photo-picker limited access may hide results.

**Limit:** It cannot recover permanently deleted content from encrypted internal storage. No root, raw-disk scanning, or cloud access. The GitHub Actions workflow builds a debug APK for testing.
