# ☎️ Scam Baqi — سكام مع الصحاب (offline edition)

لعبة **3D كاملة ف المتصفح**، مبنية على فكرة لعبة ستيم *Scam With Your Friends* — ولكن **100% offline**: لا إنترنت، لا سيرفر، لا حساب، و لا نماذج AI خارجية.
كل شي محلي: المكتب 3D مولّد بالإجرائية (procedural)، الشخصيات، الحوارات، الأصوات، و «الذكاء» ديال الجرايات.

```
scam/
├── index.html               ← اللعبة (servie par أي static server)
├── style.css                ← واجهة عربية RTL
├── manifest.webmanifest     ← PWA (تثبيت ف الهاتف)
├── sw.js                    ← service worker (offline app shell)
├── icons/                   ← أيقونات (مولّدة برمجياً)
├── vendor/three.global.js   ← three.js r170 (مولّد من vendor/three.module.js)
└── src/
    ├── util.js     أدوات، RNG، تنسيق عربي/أرقام، تخزين محلي
    ├── audio.js    كل الأصوات مُصنّعة بـ WebAudio + كلام offline (TTS ديال الجهاز)
    ├── data.js     المحتوى: الشخصيات، الحيل، الترقيات، الأحداث، البوس
    ├── callers.js  محرّك الشخصيات و الحوار (شبه-AI محلي) + فهم الكتابة الحرّة
    ├── world.js    المكتب 3D: ديسكات، كابين البوس، مطبخ، لوحات، NPCs
    ├── player.js   كاميرا الشخص الأول (كلافيي + ماوس + لمس)
    ├── desktop.js  نظام نوافذ داخل اللعبة + 10 تطبيقات
    ├── calls.js    واجهة المكالمة: الثقة، الشك، الصبر، الأدلة
    ├── day.js      الشيفت، الكوتا، الأحداث، التقييم، التخزين
    ├── ui.js       القوائم، HUD، التنبيهات، شاشات النهاية
    └── main.js     الحلقة الرئيسية و ربط كلشي
```

## ▶️ كيفاش تلعب

**بلا سيرفر (أسهل حاجة):**

```
scam-baqi-offline.html     ← ملف واحد فيه كلشي: دوبل كليك و العب
```
(مولّد ب `node tools/build-scam.mjs` — ما كيحتاجش حتى شي طلب خارجي.)

**بسيرفر محلي:**
```bash
cd scam && python3 -m http.server 8000
# → http://localhost:8000
```

**ف الهاتف (بحال تطبيق):** حط المجلد ف أي استضافة، حلّ الصفحة ف Chrome/Safari → `⋮` → **تثبيت التطبيق / Add to Home screen**. من بعد اللعبة كتخدم offline بفضل `sw.js`.

## 🎯 اللعبة

- 🗓️ **7 أيام** = run كامل. كل يوم كوتا أكبر، وقت أقصر، و جراية أصعب.
- 📞 **الكولات**: كتجي كولاية → رد → هضر. عندك مؤشرات **ثقة**، **شك**، و **صبر** (الوقت الحقيقي).
- 🖥️ **Remote Access (AnyViewer)**: سرق معلومات من حاسوب الضحية (البنك، ولدو، الرصيد…) و **استعملها ف الهضرة** = ثقة أكثر + دخل أكثر.
- 💬 **الكتابة الحرّة**: كتب بالعربية/الدارجة (وأي حاجة)، و المحرك كيحلّل الكلمات المفاتيح و كيبني الرد. كتقدر تمدح، تخوّف، تعد بالفلوس، تقسم، ولا… تغلط و تسد.
- 🎨 **Paint / Recorder / Camera**: وثيقة مزيفة، تسجيل شاشة، تصويرة — كل واحدة كتزيد ف نسبة الدخل.
- 🛒 **Scamazon**: 10 ترقيات (سماعات، VPN، مضاد فيروسات، شاشة ثانية…).
- 🚨 **الأحداث**: فيروس، مداهمة شرطة، مفتش، ضربة جوية (لازم تجري للبلاصة المحمية)، ضو مقطوع (سير للقاطع)، صراخ البوس، طلبات الجيران.
- 🧑‍💻 **Scambaiters**: جراية كتلعب معاك باش تجمع دليلك → فيروس + تبليغ. العلامة: ملف «بلوكيست» + أسئلة على «رقم الملف».
- 👔 **تقييم البوس** ف نهاية كل نهار: قبلتي؟ نهار جديد و بونص. ما قبلتيش؟ **YOU ARE FIRED!**

### ⚖️ التعليم و الأخلاق
اللعبة خيال كامل (الجرايات AI خيالي، الفلوس فلوس اللعبة)، و **كل حيلة كتستعملها كتفتح «درس» ف دفتر الملاحظات** كيشرح كيفاش الناس كيتعرّفو على هاد النصب ف الواقع (الرموز السرية، الجوائز، «الرسوم الدولية»، الاستعجال…). المقصد: تفهم كيفاش كيتصاد النصب — ماشي كيفاش يتدار.

## 🧠 كيفاش خدام «الذكاء» بلا إنترنت

`callers.js` فيه:
1. **مولّد شخصيات**: 8 أنماط نفسية (طيّب، خوّاف، شكّاك، طمّاع، مغرور، عصبي، وحيد، واعي) × مدن × مهن × عادات، مع أرقام مدخرات و صبر و حساسية.
2. **قاموس كلمات مفاتيح** بالعربية/الدارجة/اللاتينية مع تطبيع الحروف (تشكيل، همزات، ة/ه…) — كيتعرّف على 20+ موضوع (بنك، جايزة، خوف، سلطة، عاطفة، تهديد…).
3. **محرّك ردود** كيركّب الجواب: صدى لكلامك («…هادي كلمة كبيرة بصح») + رد فعل حسب التغيير ف الثقة/الشك + لمسة الشخصية + objection ولا سؤال.
4. **تدرّج المراحل**: تعريف → فخ/جاذب → بناء الثقة → طلب صغير → طلب كبير → الخروج، مع عتبات للطلب (46 و 66) و «backlash» إلا سولتي بكري.
5. **الوقت**: الصبر كينقص بالثانية الحقيقية (القهوة كتزيدو، العصبي كينقصو بسرعة)، و إلا خلا، سد التيليفون.

دابا الشخصيات كتهضر بصوت الجهاز إلا كان صوت عربي (`speechSynthesis`)، وإلا كتهضر «بليب» ريترو — بجوج offline.
