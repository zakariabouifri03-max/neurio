# 🏝️ جزيرة — لعبة نجاة وبناء

لعبة عربية (بالمغربية) فالـمتصفح: كتوقع فجزيرة صغيرة فيها شجر 🌴 وحيوانات 🐐🐗🐔، خاصك تقطع، تجمع، تبني، تربّي الدجاج… وتدير مراحل مرحلة مرحلة حتى تبني القارب ⛵ وتخرج من الجزيرة.

**بلا CDN، بلا بناء (build)، بلا صورة وحدة** — كلشي مرسوم بالكود: نسخة **3D حقيقية بـThree.js** (كاينة داخل المشروع) ونسخة **2D** بالـcanvas. كل الأصوات مُصنّعة بـWebAudio.

> 🎮 **2D ولا 3D؟** اللعبة كتقلع 3D أوتوماتيك إلا كان المتصفح كيدير WebGL، وإلا كترجع 2D بوحدها. تقدر تبدّل فالوضع من القائمة، ولا بـ`?mode=2d` / `?mode=3d` فالرابط، والاختيار كيتحفظ.

### 🔗 روابط سريعة (query params)

| الرابط | شنو كيدير |
|---|---|
| `?play=1` | **كيدخل ديريكت للعب** — بلا قائمة وبلا شاشة تعليم (كيكمّل من الحفظ إلا كان) |
| `?play=1&mode=3d` | بحال فوق، ولكن مفروض 3D |
| `?play=1&seed=20240928` | جزيرة معيّنة ببذرة من الرابط (كتشارك جزيرة مع صحابك) |
| `?mode=2d` | يلعب 2D وهو متأكد |

## ▶ كيفاش تلعب

**1) بلا سيرفر — ملف HTML وحد:** حمّل `jazira-standalone.html` ودوبل كليك — كلشي داخلو (اللعبة + Three.js)، كيخدم حتى أوفلاين 🌍
(إلا بغيتي تعاود تبنيه من بعد أي تعديل: `node tools/build-single.mjs`)

**2) ولا بالسيرفر (PWA — كتزيدها للشاشة الرئيسية):**
```bash
python3 -m http.server 8000 --directory jazira
# من بعد حل: http://localhost:8000
```

> اللعبة كتخدم حتى أوفلاين (PWA) — تقدر تزيدها للشاشة الرئيسية فالتيليفون 📱

## 🕹️ التحكم

| الحركة | الأزرار |
|---|---|
| المشي | `WASD` / الأسهم — ولا عصا التحكم فالتيليفون |
| ⚡ التفاعل (قطع، جمع، هدرة، ركوب) | `SPACE` ولا زر ⚡ |
| الجري | `SHIFT` (كيستعمل الطاقة ⚡) |
| الوصفات | `C` |
| الشنطة | `I` |
| الصوت | `M` |
| القائمة/إيقاف | `ESC` |

### 🎥 الكاميرا (فقط فالوضع 3D)

| الحركة | الأزرار |
|---|---|
| الدوران | دوز السفارة (drag) ولا `Q`/`E` |
| القرب/البعد | عجلة الفارة (wheel) ولا قرصة بجوج صوابع — ولا `Z`/`X` |
| الرجوع من ورا اللاعب | أوتوماتيك من بعد ما تسكت على الكاميرا شي ثانية |

## 🎯 المراحل (7 مراحل)

1. **أول نهار** — قطع 10 خشب 🪵 · 6 حجر 🪨 · 8 ألياف 🌾
2. **المخيم** — صنع الفأس 🪓 · بناء نار المخيم 🔥 · الكوخ 🏠
3. **الدجاج 🐔** — بناء قفص الدجاج · توليف 2 دجاجات (بالزر 🌱 3 مرات) · جمع 6 بيض 🥚
4. **الطياب والماء** — طابلة الخدمة 🛠️ · 4 ماكلات مطهيّة 🍖 · 6 راتنج 🫧 · شرب من العين 💧
5. **الحبال والشراع** — 6 حبال 🪢 · شراع 🪧
6. **القارب ⛵** — بناء الهيكل وتكميلو (خشب/ألياف/حبال/شراع)
7. **البحّار 🧭** — اركب القارب… وداعاً الجزيرة! 🌊

## ✨ شنو كاين فاللعبة

- 🗺️ **جزيرة عشوائية** كل مرة (بذرة/seed): شاطئ، غابة، صخر، عيون ماء، مناخ مختلف
- 🌗 **ليل ونهار** — بالليل كتبرد 🥶 خاصك نار ولا الكوخ، والخنازير البرية كتولّي خطيرة 🐗
- 🐔 **تربية الدجاج**: دير بزر فاليد ووقف — الدجاجة كتقرب ليك بوحدها → عطيها 3 مرات → تولّف وتتبعك → دوّزها للقفص → كتنتج بيض
- ⛏️ **أدوات**: فأس (خشب بزربة) ومعول (الحجر الكبير)
- 🍳 **طياب فوق النار**: لحم مطهّي، أومليت، وأكل جوز الهند 🥥
- 🐐 **صيد** بالعنزات والخنازير (اللحم كيرجع يتكاثر 😉)
- 🛌 **نعاس** فالليل باش تدوز للصباح
- 🗺️ **خريطة صغيرة** فالركن باش ما تتيهش
- 💾 **حفظ تلقائي** — تقدر توقف وترجع منين بغيتي
- 🌅 **مناخ حي 3D**: شمس كتدور، سماء كتّبدل لونها، نجوم بالليل، موج فالما، ضوا نار كيقوى بالليل، وتفاصيل كتّبان مرحلة بمرحلة فالمرمى

## 🧱 التقنية

```
jazira/
├── index.html            # الصفحة
├── manifest.webmanifest  # PWA
├── sw.js                 # service worker (أوفلاين)
├── vendor/
│   └── three.module.js   # Three.js (r170) — داخلة للمشروع، ماشي من CDN
├── tests/                # اختبارات كتخدم بـNode بلا متصفح
└── src/
    ├── main.js     # البداية: اختيار 2D/3D، كشف WebGL، الرجوع التلقائي
    ├── game.js     # المنطق: مراحل، حرف، حفظ، مؤثرات (مشترك بين 2D و3D)
    ├── view2d.js   # المصيّر 2D (canvas)
    ├── view3d.js   # المصيّر 3D (Three.js): مشهد، كاميرا، آلاف الرسم
    ├── models3d.js # نماذج 3D مرسومة بالكود (شجر، حيوانات، قارب…)
    ├── geom3d.js   # أدوات الهندسة (صناديق، أسطوانات، دمج، ألوان)
    ├── render.js   # أطلس الرسومات 2D
    ├── world.js    # توليد الجزيرة، التصادم، الموارد
    ├── entities.js # اللاعب + ذكاء الحيوانات
    ├── ui.js       # HUD، القوائم، الوصفات، أزرار اللمس
    ├── audio.js    # أصوات WebAudio
    ├── data.js     # العناصر، الوصفات، المراحل
    └── util.js     # أدوات (ضجيج، RNG، وقت)
```

- **الرسم 2D**: كل الرموز مرسومة بالكود فأطلس واحد، والأرض كترسم بالقطع (chunks) وكتخزن مؤقتاً
- **الرسم 3D**: الأرض ميش واحد مبني من نفس ارتفاعات البلاطات (1 بلاطة = 1 وحدة)، والأغراض كترسم `InstancedMesh` (نسخ بزربة)، والظلال كتطيح أوتوماتيك فالتيليفون باش يبقى سريع
- **الأداء**: ~60 FPS — الأرض ما كتعاودش تبنى، الكاميرا كتلحق اللاعب، والجزيئات محدودة
- **الحجم**: تبعية وحدة داخلية (Three.js) — كلشي ~1.4 ميغا بلا ضغط

## 🧪 الاختبارات

الاختبارات كتخدم بـNode وحدو (بلا متصفح)، وكتستعمل نفس كود اللعبة:

```bash
cd jazira
node tests/test-logic.mjs     # منطق اللعبة: 53 اختبار
node tests/test-3d.mjs        # مشهد 3D: 39 اختبار
node tests/test-visual.mjs    # الكاميرا والمشهد بلا متصفح: 37 تفتيش
node tests/test-ui.mjs        # الواجهة (كيحتاج jsdom، وإلا كيتخطى)
node tests/autoplay.mjs 20240928      # روبوت كيلعب 2D حتى للقارب
node tests/autoplay.mjs 20240928 3d   # نفس الشي فالوضع 3D
node tests/test-single.mjs    # الملف الوحد: كيبنيو، كيحلو، وكيتأكد بلي كيخدم (26 اختبار)
```

> 🧱 `tools/build-single.mjs` كيجمع كل الوحدات (وThree.js) فسكريبت وحد داخل HTML — بلا أي تبعية خارجية.

الروبوت كيوصل للمرحلة 7 وكيهرب فـ~4 دقايق فالوضعين (0 مرات موت).
