What this extension can and cannot do

It can

  • Read exactly how many seconds of video are buffered ahead of the playhead.
  • Measure real download throughput from the player's own media requests.
  • Predict when the buffer will run out, seconds in advance.
  • Pause briefly so the player fills further ahead, then resume.
  • Stop its own telemetry-blocking rules from competing with video bytes.
  • Optionally pace playback a few percent slower to convert throughput into buffer.

It cannot

  • Increase your bandwidth. A 2 Mbps connection stays 2 Mbps.
  • Make 1080p stream on a link that is permanently slower than 1080p's bitrate — nothing can.
  • Choose which byte ranges YouTube's player fetches; that is decided by YouTube's DASH client.
  • Rewrite or proxy media segments — Chrome's security model does not allow it here.
  • Change your resolution, and it never will: there is no code path that selects a lower quality.

Example. On a 2 Mbps line a 1080p stream may need ~3.5 Mbps. The extension cannot close that gap. What it can do is make sure the little headroom you have is spent downloading video ahead of you, and pause for two seconds now instead of letting the player stall for ten seconds later. If the shortfall is permanent, the honest fix is a lower resolution — which is your call, not the extension's.

Privacy

  • Manifest V3, no background pages, no remote code.
  • No external servers. Every byte stays inside your browser.
  • No tracking, no analytics, no ads, no affiliate links.
  • No browsing history is read or stored. The only persisted data is this settings object.
  • Runs on youtube.com, www.youtube.com and m.youtube.com only.
  • Permissions requested: storage (your settings) and scripting (to read the player's quality on YouTube pages). declarativeNetRequest is optional and only asked for if you enable request reduction.
  • Telemetry data collected by this extension: none. It does not phone home, because there is no home to phone.
