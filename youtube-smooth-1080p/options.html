What this extension can and cannot do

YouTube controls its DASH/adaptive media requests. Chrome does not provide extensions a reliable way to prioritize individual stream segments, so this extension does not rewrite requests, force preloading, or change resolution. It monitors the media element and player APIs, estimates the network only when Chrome exposes that estimate, and can manage a brief playback pause.

1080p stays 1080p. If the connection cannot deliver enough data, buffering may still happen.

No external server · no tracking · no browsing history Preferences are stored locally in Chrome.
