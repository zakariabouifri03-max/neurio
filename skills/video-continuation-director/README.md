# Video Continuation Director for Dola AI

An instruction-only Dola skill that continues an uploaded or previously generated video while preserving visual and motion continuity.

## Install in Dola

1. Open **Skills**.
2. Click **Install** and choose the local skill upload option.
3. Upload `video-continuation-director-dola.zip` (or select this folder).
4. Wait for Dola's security review to finish, then enable the skill in a new chat.

## Example requests

- `Continue this video for 8 seconds. Keep the same character and camera movement.`
- `Make the next scene without a visible cut. The car reaches the tunnel and slows down.`
- `Continue the last video you generated. Keep everything consistent and end on a stable frame.`

The skill defaults to an 8-second natural continuation when no duration or story direction is supplied.
