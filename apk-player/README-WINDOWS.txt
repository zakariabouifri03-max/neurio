NEURIO APK PLAYER 1.0 - play Android HTML5 games on Windows, without an emulator
================================================================================

HOW TO USE
  (BashBaqiRacing-1.0.1.apk in this zip is a game you can try right away.)
  1. Double-click NeurioApkPlayer.exe
     (on an old 32-bit Windows use NeurioApkPlayer-32bit.exe).
  2. Click "Open APK" and pick your .apk  -- or drag the .apk onto the window,
     or onto the .exe icon itself.
  3. Play! The game is added to your library, so next time it is one click away.
     The pin button creates a desktop shortcut that opens the game directly.

KEYS
  F11 or Alt+Enter   fullscreen
  F2                 touch mode on/off (in touch mode the mouse acts like a finger)
  F1                 back to the library
  F5                 restart the game
  Ctrl+M             mute
  (Esc is left to the game.)

WHAT WORKS
  Games and apps made with web technology: HTML5 / JavaScript games, Cordova,
  Capacitor, Construct, Phaser, PixiJS, Three.js, Babylon.js and WebView wrappers
  such as Bash Baqi Racing. Saves (localStorage / IndexedDB) are kept.

WHAT DOES NOT WORK
  Native Android games (Unity, Unreal, Godot, Flutter, Java/Kotlin apps...).
  Their code needs a real Android system; the player detects them and tells you.
  For those, use a light emulator (LDPlayer / MuMu on low settings) or Bliss OS.

NOTES
  * Needs the Microsoft Edge WebView2 Runtime. It is already part of Windows 10
    and 11; if it is missing, the player offers the free download.
  * Windows SmartScreen may say "Windows protected your PC" because the program is
    new and not signed: click "More info" -> "Run anyway".
  * Your data lives in %LOCALAPPDATA%\NeurioApkPlayer.
    Portable mode: put an empty file named portable.txt next to the .exe and the
    data is stored in a NeurioApkPlayerData folder beside it (good for USB sticks).
