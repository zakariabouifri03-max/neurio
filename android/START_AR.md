# نيوريو (Neurio) — بث ألعاب عبر الشبكة المحلية — ابدأ من هنا

مشروع أندرويد كامل. **جاهز للفتح في Android Studio**، وليس ملف APK جاهز
(لا يمكن بناء APK هنا لأن بيئة التطوير غير متوفرة في هذا السيرفر: لا Java،
لا Gradle، لا Android SDK، ولا إنترنت). أول بناء حقيقي يكون عندك في Android Studio.

---

## 1. حمّل واستخرج

- نزّل `neurio-android.zip` ثم فكّ الضغط عنه (Extract / Unzip).
- غادي تلقى مجلد **`android/`** — هذا هو المجلد المهم.

## 2. افتح المشروع في Android Studio

1. `File` ▸ `Open…`
2. اختار **مجلد `android`** (ماشي المجلد الكبير لي فوقو).
3. Android Studio غادي يقترح عليك يعمل Sync — اقبل.
   - إلا جاك خطأ ديال **gradle wrapper jar**، اكتب فالطرفية (Terminal) جوه Android Studio:
     ```
     ./gradlew wrapper --gradle-version 8.7
     ```
     أو بساطة: `File ▸ Sync Project with Gradle Files` (كاين مسبقًا `gradle/wrapper/gradle-wrapper.properties` صحيح).

## 3. ثبّت على الهاتفين

- شبك الهاتفين على نفس الـ Wi‑Fi (يفضّل 5 GHz).
- `Run ▸ Run 'app'` على **الهاتف المضيف** (Phone 2 = اللي فيه اللعبة مثبّتة).
- نفس العملية على **هاتف المشاهد** (Phone 1 = **اللي ما فيهش اللعبة، وما غادي يتحمّلها ولا تتثبّت فيه**).

## 4. قبل ما تلعب — فعّل الإدخال على الهاتف المضيف

`الإعدادات ▸ إمكانية الوصول (Accessibility) ▸ Neurio remote input ▸ فعّل`

بلا هاد الخطوة، الفيديو غادي يخدم مزيان ولكن اللمسات ما غاديش توصل للعبة
(أندرويد ما كيسمحش لتطبيق يدخل اللمسات فتطبيق آخر بلا خدمة إمكانية الوصول).

## 5. شغّل الجلسة

**الهاتف المضيف:** `HOST GAME` → اختار اللعبة → وافق على التقاط الشاشة →
اللعبة كتحرّج أوتوماتيكيًا، والشاشة كتعطيك **رمز من 6 أرقام** + IP.

**هاتف المشاهد:** `JOIN GAME` → كيبان المضيف أوتوماتيكيًا (mDNS + UDP)،
أو دخّل الـ IP يدويًا → دخّل الرمز → `CONNECT`.
